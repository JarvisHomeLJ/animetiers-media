Privacy Policy — LKS AnimeTiers Tool

Last updated: July 12, 2026

LKS AnimeTiers Tool is a personal desktop tool that uploads the owner's own anime ranking videos from the owner's computer to the owner's own social accounts (TikTok/Instagram, @animetiers_).

  • Data collected: The tool only accesses the explicitly linked accounts of its owner (basic profile info and video upload on the owner's behalf). No data of other users is collected, stored, or processed.
  • Storage: Access tokens are stored locally on the owner's machine only. There is no external server and no database.
  • Sharing: No data is shared with, sold to, or disclosed to third parties.
  • Tracking/Ads: The tool uses no tracking, no cookies, and no advertising.
  • Deletion: The connection can be revoked at any time in the platform settings (e.g. TikTok: Settings → Security → Apps and websites); locally stored tokens can be deleted at any time.
